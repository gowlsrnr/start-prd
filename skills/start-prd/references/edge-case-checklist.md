# 엣지케이스 결정 트리 (범용 SaaS)

Phase 3-1에서 사용한다. **평면 체크리스트가 아니라 트리의 진입점 목록이다.**

사용법:
1. 각 진입점의 **루트 질문**을 먼저 정한다
2. 루트 답에 따라 **가지 질문**이 열린다 — 답이 "아니오"면 그 가지는 통째로 닫힌다
3. 여기 없는 하위 질문이 떠오르면 이어서 묻는다. 그게 정상이다
4. 결정형 질문이므로 **한 번에 하나씩, 추천안과 근거를 붙여** 묻는다

**흔한 기본값**은 대부분의 SaaS에서 무난한 출발점이지 정답이 아니다. Phase 0 맥락과 충돌하면 맥락이 이긴다.

전부 답할 필요는 없다. 다만 **읽지 않고 건너뛰는 것**은 금지 — "해당 없음"도 이유 한 줄을 남긴다.

---

## 1. 권한·역할

**루트: 이 기능이 역할에 따라 다르게 동작하는가?**

- 역할별로 보이는가 / 보이지만 막히는가 / 아예 없는가
- 권한 없는 사용자가 직접 URL로 접근하면 → *흔한 기본값: 404 (403은 리소스 존재를 알려준다)*
- 작업 도중 권한이 회수되면
- 마지막 관리자가 스스로 권한을 내릴 수 있는가 → *흔한 기본값: 차단*
- 남이 만든 것을 수정·삭제할 수 있는가

## 2. 상태·라이프사이클

**루트: 이 기능이 다루는 객체에 상태가 있는가?**

- 가질 수 있는 상태를 전부 나열했는가 (중간 상태 포함)
- 상태 전이표 — 갈 수 있는 경로와 **못 가는 경로**
- 처리 중 사용자가 이탈하거나 새로고침하면 → *흔한 기본값: 서버 기준 상태 유지, 재진입 시 이어보기*
- 시간이 지나면 만료되는가 → 만료 시 자동 전이 대상
- 되돌릴 수 있는 전이와 없는 전이 구분

## 3. 실패·에러

**루트: 이 동작이 실패할 수 있는가? (외부 호출·비동기·다건 처리가 있으면 예)**

- 타임아웃 시 사용자에게 보이는 것
- **부분 성공** — 10건 중 3건만 성공하면 → *흔한 기본값: 성공분 유지 + 실패분 목록 제시 + 실패분만 재시도*
- 중복 클릭·중복 요청 → *흔한 기본값: 서버에서 멱등 처리*
- 외부 시스템·결제·메일 실패 시 롤백되는가
- 재시도가 자동인가 수동인가
- 에러 문구가 사용자 언어인가 개발자 언어인가

## 4. 빈 상태·규모

**루트: 목록·집계를 보여주는 화면이 있는가?**

- 0건일 때 (첫 사용자가 보는 화면) — 안내 문구와 다음 행동 유도
- 1건일 때 정렬·필터가 어색해지지 않는가
- 아주 많을 때 → 페이지네이션·검색·성능 임계값
- 검색·필터 결과가 0건일 때 (빈 상태와 다르게 처리)
- 이름이 아주 길 때의 레이아웃

## 5. 데이터

**루트: 이 기능이 데이터를 만들거나 지우는가?**

- 삭제 시 연관 데이터 → 함께 삭제 / 남김 / 삭제 차단
- 논리 삭제인가 완전 삭제인가, 복구 가능한가 → *흔한 기본값: 논리 삭제 + 보관 기간*
- **기존 데이터 마이그레이션** — 이미 만들어진 것들은 어떤 값을 갖는가 → *가장 자주 누락되는 항목*
- 중복 생성 허용 여부 (같은 이름, 같은 대상)

## 6. 동시성·멀티유저

**루트: 두 사람이 같은 대상을 동시에 건드릴 수 있는가?**

- 동시 수정 → *흔한 기본값: 나중 저장이 덮어쓰되 변경 감지 시 경고*
- 한 사람이 여러 탭을 열어둔 경우
- A의 변경을 B가 언제 보는가 → 실시간 / 새로고침 후
- 중복 요청·중복 승인 처리

## 7. 과금·한도

**루트: 이 기능이 플랜·한도·비용에 닿는가?**

- 플랜별 제한이 다른가
- 한도 초과 시 → 막기 / 경고만 / 초과 과금
- 이 동작이 과금 계산에 반영되는가
- 업·다운그레이드 시 이미 만든 것들은
- 미납·정지 상태에서 동작하는가

## 8. 알림

**루트: 이 동작이 다른 사람에게 알려져야 하는가?**

- 누구에게 어떤 채널로
- 대상자가 알림을 꺼둔 상태라면
- 대량 발생 시 묶어서 보내는가
- 발송 실패해도 동작 자체는 성공 처리되는가 → *흔한 기본값: 예, 알림은 비동기 부수 효과*

## 9. 입력·검증

**루트: 사용자가 값을 입력하는가?**

- 필수/선택, 길이 제한, 허용 문자
- 공백만 입력, 특수문자, 이모지, 다국어
- 중복 이름 허용 여부
- 숫자 — 0, 음수, 소수점, 상한
- 날짜 — 과거 날짜, 시간대 기준

## 10. 접근 경로·환경

**루트: 이 화면에 들어오는 경로가 둘 이상인가?**

- 진입 경로 목록 (메뉴·딥링크·알림 클릭·검색·공유 링크)
- 뒤로가기·새로고침 시 입력값 유지
- 좁은 화면에서의 동작
- 로그아웃 상태에서 링크를 열면 → *흔한 기본값: 로그인 후 원래 목적지로 복귀*
- 세션 만료

## 11. 취소·되돌리기

**루트: 시간이 걸리거나 되돌리기 어려운 동작인가?**

- 진행 중 취소 시 어디까지 되돌아가는가
- 실수 복구(undo) 제공 여부
- 누가 언제 무엇을 했는지 기록이 필요한가 → *감사 로그는 권한·과금·삭제에 닿으면 대체로 필요*

## 12. 보안·프라이버시

**루트: 다른 사용자·다른 조직의 데이터에 닿을 수 있는 경로인가?**

- 조회 경로에서 소유권 검증이 어디서 이뤄지는가
- 개인정보가 화면·로그·URL에 노출되는가 → **URL 쿼리스트링에 식별정보 금지**
- 공유 링크가 있다면 만료·권한 범위
- 데이터 내보내기 허용 범위
